# tools

## seo-report.py

시호한의원의 검색 노출을 측정합니다. 매일 아침 9시 루틴이 이 파일을 실행합니다.

```
python3 tools/seo-report.py           # 표로 출력
python3 tools/seo-report.py --json    # JSON (히스토리 적재용)
```

측정 항목은 두 축입니다.

**사람이 직접 검색** — 네이버 통합검색에서 플레이스(지도) 블록 내 시호한의원의
순위, 그리고 웹문서 탭에서 thesiho.kr이 몇 위 몇 페이지에 있는지.

**AI 검색 준비 상태** — GPTBot·ClaudeBot·PerplexityBot·OAI-SearchBot·
Google-Extended가 실제로 접근 가능한지, llms.txt·robots.txt·사이트맵이
응답하는지, 구조화 데이터가 출력되는지.

### 측정할 수 없는 것

ChatGPT나 Claude가 실제 답변에서 시호한의원을 인용하는지는 이 스크립트로
알 수 없습니다. 각 서비스의 답변을 조회할 방법이 없기 때문입니다.
루틴에서 WebSearch로 몇 개 질의를 던져 색인 등재 여부를 대리 지표로 봅니다.

구글과 다음은 자동 조회를 차단합니다(302/301). 구글 순위는 서치콘솔의
실적 보고서에서 확인하세요. 실제 노출·클릭·평균 게재순위가 나옵니다.

### 키워드 수정

`KEYWORDS` 리스트를 고치면 됩니다. 지역명을 붙인 형태와 붙이지 않은 형태를
함께 넣어두었습니다. 비지역 키워드는 경쟁 강도를 보기 위한 참고용입니다.

### 히스토리

루틴이 `seo-history` 브랜치의 `rank-history.jsonl`에 매일 한 줄씩 적재합니다.
데이터 전용 브랜치이므로 main에 머지하지 않습니다.
